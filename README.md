Selenium Automation – Hybrid Framework

Project Description :
This project is a Selenium Automation Testing framework developed using Java to automate key user functionalities of the TutorialsNinja Demo E-commerce Website: http://tutorialsninja.com/demo/
The framework automates end-to-end user flows such as user registration, login, and device search, following a Hybrid Framework design for better scalability and maintainability.

---
Application Under Test :
Website: Tutorials Ninja Demo
Domain: E-commerce  
URL: http://tutorialsninja.com/demo/

---
Tech Stack :
- Programming Language: Java  
- Automation Tool: Selenium WebDriver  
- Test Framework: TestNG  
- Build Tool: Maven  
- Design Pattern: Page Object Model (POM)  
- Test Data Sources: 
  - Property files (configuration & static data)  
  - Excel sheets (data-driven testing)

---
Test Reports :
- Test execution is managed using TestNG
- Reports include:
  - Passed / Failed test cases
  - Execution summary
- Reports are generated after test execution
- Automatic screenshot capture on failure
- Timestamped execution details
- Easy-to-read HTML report

---
Automated Test Scenarios :
- User Registration  
- User Login  
- Search Devices / Products after successful login  

---
Framework Type :
Hybrid Automation Framework
- Page Object Model (POM)
- Data-Driven testing using Excel
- Configuration handling using Property files
- Test execution and management using TestNG
- Generating the report using Extent Reports
